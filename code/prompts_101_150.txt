# GLOBAL BACKTEST RULES FOR ALL 50:
# - Signal on candle close, enter next candle open. No lookahead, no repainting.
# - If stop loss and take profit are both hit in the same candle, assume stop loss hit first.
# - Fees and slippage ON:
#   BTC/ETH: 0.04% per side + 1 bp slippage
#   SOL/HYPE/SUI/JUP: 0.06% per side + 3 bp slippage
#   NVDA/SPCX: $0.005 per share + $0.02 slippage
# - Risk 0.5% of equity per trade. No martingale, no averaging down.
# - Max 3 losing trades per day. Max 6 trades per day for 1m/3m scalps.
# - No trailing stop unless the strategy explicitly says so.
# - Backtest full history available.
# - Show: net return, max drawdown, profit factor, trade count, buy and hold.
# - Also show: 70/30 chronological in-sample/out-of-sample results, fee drag, average trade, expectancy.
# - If out-of-sample trade count is below 200, label the result fragile.
# - If required data is unavailable, skip the strategy. Do not fake it with price-only data.
# - SL = stop loss, TP = take profit, R = risk multiple, ATR = Average True Range.

108. Build a fair-value-gap continuation strategy on BTCUSDT 3 minute.
